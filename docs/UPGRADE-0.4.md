# 0.4.0：工作区会话入口

0.4.0 移除「项目与连接」和工作室内独立聊天。请在 dsh 工作区打开项目会话，使用 @设计工作室；首页快捷按钮也将任务发送到该会话。旧设置、组件映射和历史会话继续保留，不自动迁移或删除。旧 API 不再以 settings.projectRoot 决定任务目录，带项目的页面请求必须提供当前 sessionId，由宿主读取真实 cwd。

MasterGo 不再通过页面的 connect/mastergo 创建全局连接，而在 design_workspace 工具中按 Agent 作用域自动连接；每个会话的 cwd 固定在发起任务时。外部自动化应调用当前会话的设计工具，不设置全局项目目录。Reborn 只读组件服务继续共享。

会话参与标记来自已提交的 @ 指定或设计工具调用，表示「此会话已使用设计工作室」，不冒充运行状态。由新增 studioDesign 投影从已有事件重建，不新增 Session 事件或修改格式。任务状态与停止操作继续由原会话负责。

设置中的 GitHub、内置、本地知识库与高级 MCP 参数保留。仓库与版本信息收进版本详情，原组件映射仍参与任务指引；预览按项目目录独立保存。回退前保留 0.3.0 包和 DSH_HOME 备份。
