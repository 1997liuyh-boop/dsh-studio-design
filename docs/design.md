# 设计工作室 0.1

独立插件注册设计工作室，复用共享 SDK 卡片与 studio 控制工具。Vue 页面使用 Tailwind；三个连续区域承载项目与连接、设计与组件、代码与预览。

项目先复用已有组件，再选择 Reborn，最后补充自定义组件。读取 package.json、components.json、TypeScript 别名及主题配置文件位置，不执行配置文件。设计节点与代码组件通过显式映射关联；不推断两个 MCP 自动具有同名组件。

MCP 传输由 dsh-mcp-client 管理。用户明确连接后启动子插件；重新连接、切换项目和卸载都会释放旧连接。使用真实工具登记状态判断连接，不以端口开放冒充可用。

生成任务进入标准 dsh 会话，模型通过现有工具修改目标项目。请求携带当前项目配置、组件映射和生成约束，进入会话日志。工作室不会私自覆盖业务文件、安装全部组件或自动把代码回写画布。画布同步仅在用户点击后请求，并只使用静态 HTML。

项目记录按真实路径摘要保存到 DSH_HOME/studio/design。使用版本摘要拒绝过期写入；保存通过临时文件替换。配置与生成的网页不能进入公开源码包。预览只接受回环 HTTP 地址，使用不带 same-origin 权限的 iframe；服务由用户或 dsh 会话按目标项目脚本启动。

首版覆盖 Vue Web。UniApp 项目可识别并提示暂不支持生成。MasterGo 必须运行桌面客户端并打开设计文档；未连通时显示失败，不返回演示数据。

实施与验收：项目解析及状态存储 → MCP 生命周期 → Vue 工作台及标准会话 → 配置/映射/连接失败/会话关联测试 → 独立构建与包检查 → 真实宿主加载 → GitHub 发布。未实际连通 MasterGo 或完成模型生成时，必须在交付说明中标明。
